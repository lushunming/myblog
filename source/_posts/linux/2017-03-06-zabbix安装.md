# zabbix安装



## 环境


Ubuntu 16.04.2 LTS（阿里云）

## 安装步骤




1. 安装zabbix仓库
    ```
    # wget http://repo.zabbix.com/zabbix/3.0/ubuntu/pool/main/z/zabbix-release/zabbix-release_3.0-1+xenial_all.deb
    # dpkg -i zabbix-release_3.0-1+xenial_all.deb
    # apt-get update
    ```

2. 安装zabbix server和mysql

    - 安装zabbix服务和mysql和前端
    ```
     # apt-get install zabbix-server-mysql zabbix-frontend-php
    ```

    - 初始化数据库
   
    ```
        shell> mysql -uroot -p <root_password>#连接数据库
        mysql> create database zabbix character set utf8 collate utf8_bin;
        mysql> grant all privileges on zabbix.* to zabbix@localhost identified by '<password>'; #新建zabbix用户
        mysql> quit;
    ```
    - 初始化数据库
     初始化数据库并且导入数据。
    ```
      # zcat /usr/share/doc/zabbix-server-mysql/create.sql.gz | mysql -uzabbix -p zabbix
    ```

    - 配置zabbix服务的数据库信息
 
    ```
      # vi /etc/zabbix/zabbix_server.conf
        DBHost=localhost
        DBName=zabbix
        DBUser=zabbix
        DBPassword=<password>
    ```

    - 开启zabbix服务并且设置开机自启动

    ```
    # service zabbix-server start
    # update-rc.d zabbix-server enable
    ```
    - zabbix前端的配置
    zabbix前端的配置文件在`/etc/zabbix/apache.conf`,需要去掉`date.timezone`的注释，并且设置为`Asian/Shanghai`。（ **后面可能还会出现一些提示你条件不满足，只需要运行命令安装对应的文件就可以了**）
    ```
        php_value max_execution_time 300
        php_value memory_limit 128M
        php_value post_max_size 16M
        php_value upload_max_filesize 2M
        php_value max_input_time 300
        php_value always_populate_raw_post_data -1
        # php_value date.timezone Europe/Riga
    ```
    然后重启前端服务

    ```
        # service apache2 restart
    ```
    - 安装前端

    打开`url：http://<server_ip_or_name>/zabbix`
    点击下一步带设置数据库：
    ![此处输入图片的描述][1]
    输入可用的数据库信息。到此使用默认的用户名密码登录：`The default user name is Admin, password zabbix`。
